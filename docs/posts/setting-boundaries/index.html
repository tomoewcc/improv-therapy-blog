如何設立界線？說「不」之後，再說「因為」

作者：王家齊 ・ 發布 2026-10-03 ・ 瀏覽 —

設立界線，不是要對方改變。是把你的「不」和你的「因為」講清楚。

很多人以為界線就是說「不」，說完對方就該照做。但這樣想，界線反而很難守。

為什麼關係裡需要界線？

有毒的關係，其實是一種權力的滲透：它滲透過你的界線。所以我們要做的，是重新把這條界線架回來。

設立界線，不是要對方改變

大家大概都知道：界線，就是說「不」。

可是我們常常說完「不」之後，就很希望對方一定要理解、一定要接受這個「不」。

但其實，設定界線並不是要對方改變。

說不的時候，把「因為」一起講清楚

設定界線是：我說了不，並且把我為什麼說不，講清楚。

比如孩子問：「今天可以不要倒垃圾嗎？」

「不，你要去倒垃圾。因為我們已經講好了，今天輪到你，而我今天不想給你一個例外。」

小孩可能還是會跟你凹到底。但當你把「不」跟「因為」講清楚的時候，你就把那條線畫清楚了。

你正在練習說：我說不，而且我有我的原因。

對方不接受怎麼辦？那是下一步的事

你接不接受這個原因、你聽不聽，那可以是後面的拉扯或談判。

但在這一刻，我已經把自己的立場表態清楚了。這很重要，這是第一步。

說到一半就吞回去的人，先用身體練習

如果你常常說不說到一半，就吞回去了，不管是因為希望關係和諧，還是害怕摩擦衝突，我推薦一個在創傷治療的專業訓練裡學過的練習。

找一段你自己的時間和空間，不要有其他人在。

把你的手慢慢往外推，往外伸展開來。感覺你的手往前可以伸到哪裡，往旁邊可以到哪裡，往後可以到哪裡。你會畫出一個空間。

這個空間，就是你實體的、物理的界線。

邊做，邊說出來。如果還不太習慣，也可以在心裡說：

這是我的空間，沒有我的允許，誰也不可以進來。

界線常常是抽象的，說不出來，也抓不住。用身體先畫一次，那條線就有了一個具體的樣子。

被情緒勒索的時候，界線為什麼特別難守？

很多人說不出口，是因為一說不，就覺得自己好像做錯了什麼。

情緒勒索，一言以蔽之，就是引發別人的內疚感：我是不是太自私了？我如果不聽他的，他會不會生氣、會不會傷害自己？那我只好聽他的了。

關鍵字是兩個字：只好。

但不是讓你不舒服的，都叫情緒勒索。上班不舒服、被交辦事情也不舒服。要看的是：這件事合不合理？是不是我的責任？

明明白白表達立場的，都不是勒索。勒索，都發生在暗處。

所以你說「不，因為……」，本身就不是勒索；那是把話攤在明處。

常見問題

設立界線會傷感情嗎？

不一定。設立界線不是要對方改變，而是把你的「不」和「因為」講清楚。對方接不接受，可以之後再談；說清楚這一步，反而讓兩個人知道彼此的位置。

對方不接受我的界線怎麼辦？

那是下一步的拉扯或談判。界線的第一步，是你已經把立場表態清楚了，不是對方立刻照做。

怎麼分辨是情緒勒索，還是只是不舒服？

看兩件事：這件事合不合理？是不是我的責任？情緒勒索的關鍵字是「只好」：你因為內疚或害怕，只好聽他的。
